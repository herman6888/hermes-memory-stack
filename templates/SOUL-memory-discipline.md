
## 记忆卫生纪律（hermes-memory-stack）

- 常驻 memory MD 用量到 ~75% 就主动 triage（不等挤爆被动压缩）：infra 细节卸载进素材层 reference 页，删敏感/过期条目。写入前自问「这条是否适用于每一个会话？」——不是就写素材层，**原始事实绝不路由进注入记忆**。
- 三层分工：素材层存细节（日志/事实/证据链），语义索引只放指针（绝不复制正文），memory MD 只放一行版约定。
- skill 合并/删除：必须声明 absorbed_into，且在替代 skill 上重跑被删 skill 的回归用例——声明被吸收 ≠ 行为存活。
- skill 剪枝走 dream 审计（provenance 分类，闲置 ≥90d 进候选，pinned 保护），默认 dry-run 只出建议清单，人周审后放权执行。
- 备份：每日=文本增量（git 原生 diff），每周=全量二进制分片；全加密私有仓库，密钥双托管；脚本成功静默、失败告警、每周心跳。
